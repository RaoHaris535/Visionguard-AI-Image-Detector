# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability that includes credentials, personal data, or an exploitable proof of concept. Use GitHub private vulnerability reporting when it is available for this repository.

Include the affected component, reproduction steps, expected impact, and a safe test case. Do not test against deployments or accounts you do not own.

## Supported version

Only the latest commit on `main` is supported during active project development.
